# Client Reviews

## Overview
Prepares the materials for a periodic (quarterly/annual) client portfolio review meeting: performance recap, portfolio positioning, progress against goals, and discussion topics for the advisor.

## When to use this skill
- A scheduled client review meeting is coming up and materials need to be prepared.
- A user needs a recap of portfolio performance and positioning since the last review.
- A user wants talking points prepared for a client conversation.

## Inputs
- Client's current portfolio holdings and performance data since the last review period.
- Client's stated goals, risk tolerance, and any recent life/financial changes on file.
- Relevant market/benchmark context for the review period.
- Any outstanding action items from the prior review.

## Process
1. Summarize portfolio performance for the period: absolute return, relative to relevant benchmark(s), and key drivers of performance (what helped, what hurt).
2. Recap current portfolio positioning: asset allocation, notable concentrations, and any drift from target allocation.
3. Check progress against the client's stated goals (retirement funding, education funding, etc.) and note any change in trajectory.
4. Note any recommended changes (rebalancing, tax-loss harvesting opportunities, allocation shifts) for the advisor to discuss — framed as discussion points, not final decisions.
5. Follow up on action items from the prior review — were they completed, and if not, why.
6. Prepare a client-ready summary alongside more detailed advisor talking points/backup data.

## Output format
A client-facing summary (performance, positioning, goal progress) plus an advisor-facing set of talking points and discussion items, including any prior-period follow-ups.

## Notes / guardrails
- This skill prepares materials and discussion points — it does not make final investment recommendations or decisions on the client's behalf; those remain the advisor's call.
- Clearly separate factual performance reporting from advisory judgment/recommendations.
